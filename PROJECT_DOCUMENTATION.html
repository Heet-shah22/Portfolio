1. Executive Summary & Architecture Paradigm

The portfolio is engineered as a high-performance Single Page Application (SPA) utilizing the JAMstack methodology (JavaScript, APIs, and Markup). Rather than relying on a heavy server runtime or monolithic database, the entire application is pre-compiled into optimized static assets that are distributed across a globally replicated Content Delivery Network (CDN) with edge caching.

Key architectural priorities include:

  • Sub-second Navigation: Zero full-page refreshes through client-side routing.
  • Defense-in-Depth Security: Elimination of typical server-side exploit vectors (zero SQL injection, zero RCE) combined with strict HTTP security headers and anti-bot honeypots.
  • Decoupled Content Architecture: All personal data, projects, milestones, and skills are isolated in strongly-typed data contracts (src/data/) to enable effortless maintenance without touching presentation code.
  • Search Engine Dominance: Native XML sitemap, canonical metadata, Open Graph cards, and structured Google Search Console verification resulting in #1 ranking on Google.

4. Security Architecture & Threat Defense

OWASP & Defense-in-Depth Measures
Enterprise-grade security configuration
  • No Server-Side Vulnerabilities: Absence of SQL/NoSQL databases and backend Node execution completely eliminates SQL Injection (SQLi) and Remote Code Execution (RCE).
  • XSS Protection: Built exclusively with React Virtual DOM data-binding. Zero occurrences of dangerouslySetInnerHTML.
  • Clickjacking Defense: X-Frame-Options: DENY header in vercel.json prevents malicious framing.
  • MIME Sniffing Block: X-Content-Type-Options: nosniff forces strict MIME interpretation.
  • Spam & Bot Mitigation: The contact form includes an invisible honeypot (_gotcha) field. Bots filling this field are silently rejected by Formspree.
  • Hardware-Accelerated UX: Standard native cursor eliminates CPU layout thrashing and UI thread blocking.
