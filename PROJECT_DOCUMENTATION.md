## 4. Security & Hardening Architecture

Built specifically with a **Cyber Security & Forensics** defensive posture:

1. **Immune to SQL/NoSQL Injection:** Zero database endpoints exposed to public HTTP traffic.
2. **Immune to Server RCE:** Static pre-compiled edge architecture; no server runtime running user input.
3. **Cross-Site Scripting (XSS) Prevention:** React automatically escapes all variables before DOM injection. Zero instances of `dangerouslySetInnerHTML`.
4. **Clickjacking Protection:** Configured with `X-Frame-Options: DENY` in `vercel.json` to prevent iframe redressing.
5. **MIME Sniffing Block:** Enforced with `X-Content-Type-Options: nosniff`.
6. **Anti-Bot Spam Honeypot:** The contact form includes a hidden `_gotcha` input. Automated spam bots fill this field and are dropped automatically by Formspree.
7. **Hardware-Accelerated UX:** Standard hardware mouse pointer eliminates CPU layout thrashing and prevents UI thread freezes.
